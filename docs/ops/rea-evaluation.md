# REA 성능 평가 (계속 쓸지 판단용)

사용자 요청: REA(morluto/rea)를 실제로 써 보고 성능을 본다. 별로면 나중에 뺀다. 비교는 **토큰 사용량과 구현 가능성**으로 한다. 총괄이 이 문서를 관리한다.

## 평가 기준
| 지표 | 측정 방법 |
|---|---|
| 토큰 | REA를 쓴 에이전트 작업의 총 토큰(작업 완료 알림의 `subagent_tokens`) |
| 시간 | 작업 소요 시간(`duration_ms`) |
| 달성도 | 분석 질문별로 완전, 부분, 실패 |
| 대체 가능성 | REA 없이 grep이나 파일 읽기, 공개 문서만으로 같은 결과를 얻을 수 있었는지 |
| 구현 기여 | REA로 얻은 사실이 실제 스펙과 구현에 쓰였는지(파트 번호) |
| 비용 대비 효과 | 위 항목을 종합해 높음, 보통, 낮음 |
