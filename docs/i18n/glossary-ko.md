# 한국어 용어집 (i18n-2)

한 개념에는 한 용어만 쓴다. 번역 파일(`app/frontend/src/locales/ko/*.json`)을 고칠 때 이 표를 따른다.

| 개념 | 용어 | 쓰지 않는 표현 |
|---|---|---|
| channel | 채널 | |
| thread | 스레드 | |
| mention | 멘션 | 멘션하기(명사 자리) |
| reaction | 리액션 | 반응 |
| workspace | 워크스페이스 | |
| huddle | 허들 | |
| star | 즐겨찾기 (동사: 즐겨찾기에 추가/제거) | 별표 |
| unread | 안 읽음 (라벨), 안 읽은 메시지 | 읽지 않음 |
| reminder | 리마인더 | |
| Do Not Disturb | 방해금지 (켜기/해제) | 알림 일시 중지 |
| status | 상태 (상태 설정/지우기) | 상태 업데이트 |
| personal access token | 개인 액세스 토큰 | |
| save for later | 저장 (나중에 화면의 "저장됨") | 북마크 |
| group DM | 그룹 대화 | 그룹 메시지 |
| upload | 업로드 | 올리기 |
| moderator | 운영자 | 모더레이터 |

## 문체 규칙
- 버튼과 메뉴: 명사형 또는 "~하기" (예: 메시지 보내기, 채널 참여).
- 안내와 오류: 합니다체 ("~합니다", "~해 주세요"). "~했어요"는 쓰지 않는다.
- "{name}님"처럼 호칭 "님"은 인자에 붙여 쓴다. 조사가 받침에 따라 바뀌는 자리(을/를, 이/가, 으로/로)는 인자 뒤에 두지 않고 문장을 바꿔 피한다 (예: 리액션을 남겼습니다: {emoji}).
- 복수형 ICU는 `other` 하나만 쓴다.
- 연산자(from:, in:, has:), 단축키 이름, 제품 이름(Slawk)은 번역하지 않는다.
